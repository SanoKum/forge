# free-stream 検証結果 (run_0001_freestream_euler)

歪み非直交 hex (10^3, 閉性 1.28e-9・体積厳密に検証済み) で、一様静止場 (ρ=1.177, U=0,
P=101325, 全 slip) の forge 残差を Euler 1 ステップから逆算し、free-stream 予測
F(U_c)·r_c と成分ごとに突き合わせた。r_c = Σ_f dir·sv (セル幾何閉じ誤差, 境界面込み)。

設定: SLAU, convMethod 0(1次), viscMethod 0/visc 0, lowMachPrecond 0, timeIntegration 1。

## 結果

| 成分 | forge 残差 rms | free-stream 予測 (U=0) | 判定 |
|---|---|---|---|
| res_ro   | **0 (厳密)** | ρ(u·r)=0 | 一致 ✅ |
| res_roe  | **0 (厳密)** | ρH(u·r)=0 | 一致 ✅ |
| res_roUx | 5.87e-5 | p·r_cx | 相関 -0.68, 大きさ ~1.6倍 △ |
| res_roUy | 6.05e-5 | p·r_cy | 同上 |
| res_roUz | 5.67e-5 | p·r_cz | 同上 |

- p·r_c (float64) rms ≈ 3.6e-5。forge は 5.87e-5。
- forge残差 と p·r_c の相関 -0.68、差し引いても rms は 5.87e-5→4.29e-5 (27%減のみ)。
- 別途 float32 で組んだ r_c でも改善しない (corr -0.58)。

## 結論

1. **free-stream 保存崩れが原因で確定**。質量・エネルギー残差は厳密に 0、非ゼロなのは
   運動量のみで、その向きは圧力×幾何閉じ誤差 (p·r_c) と相関。「別機構(エネルギー式等)」
   ではない。
2. ただし運動量残差は「真の r_c」そのものではなく、**面ごとに p·s (P≈1e5 × 面積 ≈ 各項
   ~1e3) を float32 で加算しほぼ相殺した後に残る丸め誤差** (~6e-5)。atomicAdd の順序依存で
   ランダム性があり、別途計算した r_c では完全に消せない (これが 27% 減・相関0.68 の理由)。
3. 直交立方体で安定なのは、面ベクトルが軸並行で p·s が ±同値・ビット相殺し丸め誤差すら
   0 になるため。

## 修正方針への含意 (重要)

- **「セル残差で precomputed r_c を一括減算」は float32 では不十分**(本検証で 27% しか減らない)。
  大きな p·s を先に作って丸めた後では取り戻せない。
- **float32 で厳密に効く本命 = 流束を基準状態からの差で組む**: 対流流束を
  F_num(U_L,U_R) − F(U_ref) とする(U_ref=一様基準, 定数)。一様場では面ごとに
  (p_tilde − P_ref)·s が float32 でも厳密 0(等値差→0→×s=0)になり、かつ両側セルで同じ値
  なので**保存性も保つ**。大きな p·s 項自体を作らないのが要点。
- double 精度(--double メッシュ + double カーネル)でも丸めが ~1e-15 になり解決見込み。
  ただし現状 build-double は RTX3060 でレジスタ過多で起動不可。
