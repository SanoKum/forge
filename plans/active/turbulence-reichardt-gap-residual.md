## 1. 事実 (確定済み)

case/26 平板の**壁解像**解は、$y^+\approx30$ で Reichardt 対数則より約 **5% 低い**:

| ソース | 収束 | 実測/Reichardt |
| --- | --- | --- |
| forge 壁解像 (`run_0064` 等) | 全残差 `NOT CONVERGED` / $\theta$,$C_f$ は `STEADY` | 0.9492–0.9504 |
| SU2 壁解像 (`run_0049`) | 全残差収束 (rms −5.0〜−12.6) | 0.9477–0.9490 |

**両者 0.1–0.2% で一致**。独立した 2 コード (一方は全残差収束) が同じ差を示す。

## 2. 残る候補

1. **有限 $Re$** — この $Re_\theta$ 帯 (**3600–5800**、上表の 4 station 実測値) では
   対数則の漸近形がまだ成立しきっていない可能性。Reichardt 係数
   ($\kappa$=0.41, $B$ 相当 7.8) は高 $Re$ フィット。
2. **入口/前縁の扱い** — 前縁からの発達距離、入口 BL 厚さ、
   前縁特異点近傍の履歴が $y^+\approx30$ のプロファイルに残っている可能性。
3. **Reichardt 相関そのものの適合限界** — Reichardt 式は buffer 層をつなぐ内挿式であり、
   $y^+$=30 は遷移域の端。SST の解と系統差があっても不思議ではない。

## 3. 切り分けの方針 (案)

- **1 の検証**: 同一セットアップで $Re$ を上げ (または下流station で $Re_\theta$ を伸ばし)、
  実測/Reichardt が 1 へ近づくかを見る。近づけば有限 $Re$ 効果。
  上表の SU2 は $x$ 増加 ($Re_\theta$ 3632→5817) で 0.9490→0.9477 と**わずかに離れる**。
  ただし下流では $Re_\theta$ と**前縁からの履歴が同時に変わる**ので、
  これは有限 $Re$ 説の反証にはならない (手掛かり止まり)。$Re$ を独立に振る必要がある。
- **2 の検証**: 入口位置・前縁扱いを変えた run で同量を比較。
- **3 の検証**: → **実施済み (2026-08-13)**。同一 SU2 解・同一 $y_{\rm rep}$ で壁法則だけ差し替えた:

  | 壁法則 | 定数 | 実測/則 ($x$=0.451 → 0.800) |
  | --- | --- | --- |
  | Reichardt | $\kappa$=0.41, 7.8 項 | 0.9490 → 0.9477 |
  | **Spalding** | **$\kappa$=0.41, $B$=5.0** | **1.0218 → 1.0198** |
  | 純対数則 | $\kappa$=0.41, $B$=5.0 | 0.9718 → 0.9672 |

  **全法則共通ではない** (Spalding では逆に 2% 超過)。

  **ここから言えること/言えないこと (重要)**:

  - **言える**: 固定した SST プロファイルに対し、**壁法則の選択によるモデル形式差が約 7%**
    (0.948–1.022) ある。すなわち**壁法則選択は観測された 5% 差と同程度の
    モデル形式不確かさを持つ**。→ **採用した Reichardt 式・定数に対する −5% の符号付き差は
    Spalding では再現しない**。
  - **言えない**: 「差の相当部分は相関側」「Spalding が正しい」は**未確定**。
    forge と SU2 は独立コードだが**どちらも SST** なので、
    **両者に共通する SST モデル誤差は除外できていない**。
    Spalding の物理的正しさも示していない。
    **「原因が Reichardt に確定した」という意味にもしない** — 言えるのは
    「この符号付き差は採用した式・定数に固有で、別の式では再現しない」までである。
  - Spalding にも定数流儀の違いがあるため、上表の定数は必ず併記すること。
  再生成: `python3 tools/su2_wall_law_ratio.py <run>/flow.vtu --yrep 1.7681e-4 --law spalding`

## 4. 判定 — 壁関数の低摩擦バイアスに**寄与する**

この差は **forge 固有の壁関数実装バグではない** (SU2 の収束壁解像解も同値)。
しかし**壁関数と無関係ではない**: 壁解像プロファイル自身が Reichardt 相関と
$y^+\approx30$ で 5% ずれている以上、**その速度を Reichardt 壁関数へ入力すれば
$u_\tau$ は低く推定される**。端点比分解でいう**壁法則段 1.0425 (約 4.25% の寄与)** がこれ。

したがって正しい位置づけは:

> **Reichardt 相関と実際の SST 境界層プロファイルのモデル不一致**であり、
> node 壁関数の低摩擦バイアスに**寄与する**。forge 固有の実装欠陥ではない。

そして次の問題設定は「5% 差の正体は何か」ではなく:

> **なぜ Reichardt 相関はこの SST 平板境界層の $y^+\approx30$ で約 5% 高い速度を要求するのか。
> そのモデル不一致を壁関数としてどう扱うか** (相関を替える / $y^+$ を上げる / 較正する)。

§3 の壁法則スイープはこの設定への最初の手掛かりであり、
**Spalding では逆符号になる**ことから「相関の選択そのものが設計変数」だと分かる。
ただし**どの相関が正しいかは未決**であり、SST 側の共通誤差も残っている。

## 5. 次の実験 — ★ 交絡分離を先に設計する

### 5.1 壁法則は $u_\tau$ 逆解きだけに使われていない (交絡源)

[`ransWallFunction_d.cu`](../../solver_density_cuda/cuda_forge/ransWallFunction_d.cu) を読むと、
`wallLaw_reichardt_uplus` / `wallLaw_reichardt_duplus_dyp` は**4 系統**へ波及する:

| 使用箇所 | 何に効くか |
| --- | --- |
| $u^+(y^+)$ (L226) | $u_\tau$ の Newton 逆解き |
| $g=du^+/dy^+$ (L237) | `wf_pk` = $\rho u_\tau^4/\nu\cdot g(1-g)$ ($k$ 生産置換) |
| $g$ (L251) | E3 の `wf_sprod` = $S_{\rm wf}^2$ ($\omega$ 生産置換) |
| $u_\tau$ (L259–269, L294〜) | `roK_wf` / `omega_log` / **Kader 壁熱流束** |

**壁法則を丸ごと差し替えると 4 つが同時に動く**。過去に E3 で交絡した前例があるので、
**一括置換の A/B は結論に使えない**。

### 5.2 段階設計

1. **凍結場での逆解き比較 (連成前)** → **実施済み (2026-08-13)**。
   ツール `case/26.flat_plate_sst/tools/wall_law_inverse.py` ($y^+$ 帯 25–35、カラム中央値):

   | 壁法則 | A: $u_\tau$/内部基準 (壁解像場) | B: $u_\tau$ 比 (壁関数場・凍結) | B: $\tau_w$ 比 |
   | --- | --- | --- | --- |
   | Reichardt | **0.9616** | 1.0000 | 1.0000 |
   | **Spalding** | **1.0201** | **1.0599** | **1.1234** |
   | 純対数則 | 0.9805 | 1.0163 | 1.0328 |

   - **Reichardt は内部基準より中央値 3.8% 低く、採用した Spalding 式・定数は 2.0% 高い**。
     **どちらも内部基準を厳密には再現しない**。
     内部基準は**実験的真値ではない** (壁解像 SST 解自身) ので
     「Spalding が物理的に不正解」とは言わない。
   - 法則間比 Spalding/Reichardt は壁解像場 1.0608 / 壁関数場 1.0599 (**0.08% 差**)。
     ただし**同じ平板・ほぼ同じ $y^+$ 帯**で、**壁法則間比は主に $y^+$ で決まる**ため
     近い値は自然。確定範囲は「**$y^+$=25–35 で異なる 2 つの場に対し
     凍結場感度が 0.1% 以内で再現**」まで。**case/40・圧縮性では未確認**。
   - 現行ギャップ ($\tau_w$ 1.234 倍) に対し Spalding は 1.1234 倍 =
     $(1.1234-1)/(1.234-1)$ = **必要応力差の約 53%**。
     **残りの必要応答には粗場速度などが含まれる** (寄与の内訳は未確定)。
   - **注意**: Spalding の過大側 (+2%) が壁関数側の他の不足を相殺する形になりうる。
     **この相殺の符号は case/26 と case/40 で変わりうる** (E3 の前例) ので、
     採否は ③ の整合実験 + 両ケース連成 A/B まで保留する。
2. **診断実験 (機構分離用・正式仕様にはできない)** → **実装・検証済み (2026-08-13)**。
   `FORGE_WF_INV_LAW=spalding` (既定 `reichardt`)。検証結果は §6 参照。
   **逆解き則だけ**を差し替え、
   $g$ 依存閉包 (`wf_pk` / `wf_sprod`) は**現行 Reichardt に固定**する。

   **★ これは「$u_\tau$ 推定単独の効果」ではない**。連成計算では得られた $u_\tau$ が
   変わることで**壁応力・`roK_wf`・`omega_log` 経路・Kader 熱流束も同時に変わる**。
   この実験が分離するのは正確には

   > **$u^+$ 逆解き則の変更を上流介入とし、$g$ のモデル形式変更を除外した応答**

   である。**この構成は物理的に不整合なので採用候補にはしない**。

   **実装仕様** (グローバルな「壁法則切替」にはしない):

   | 項目 | 仕様 |
   | --- | --- |
   | 切替対象 | **Newton 逆解き用の $u^+$ とその微分だけ**を選択可能にする |
   | `wf_pk` の $g$ | **明示的に Reichardt 固定** |
   | E3 の `wf_sprod` | **E3 は OFF** |
   | 実験ゲート | **node + SST + `wallTreatmentSST==1` のときだけ**有効 |
   | case/40 の判定量 | $\tau_w$ に加え **$q_w$・壁温**も含める |
3. **整合実験 (実際の法則置換)** — $u^+$・$du^+/dy^+$・`wf_pk`・(必要なら E3 の `wf_sprod`) を
   **同一法則で揃える**。これが正式な採否判定の対象。
4. **連成 A/B は case/26 と case/40 の両方で** → **実施済み (2026-08-13)**。§7 参照。

### 5.3 case/40 の判定量は $\tau_w$ だけでは足りない

case/40 では $u_\tau$ が **Kader 壁熱流束**にも入るため、
**$\tau_w$ に加えて $q_w$ と壁温を判定量に含める**こと。
また圧縮性・熱伝達があるため、**非圧縮 Spalding をそのまま正式採用するのは危険**で、
圧縮性補正 (van Driest 変換等) を含めた形で評価する。

| `roK` | 1.23e-06 | 1.51e-06 |

| **`cf_momentum` (c)** | **drift 6.6%/tail `DRIFTING`** (極値が末尾) |

(c) の時系列は step 10000/15000/20000 で **0.761 / 0.798 / 0.811 と増加中**。
一方 Spalding 整合 (d) は 0.824/0.823/0.822、生 $\tau_w$ は 7.274/7.251/7.240 Pa で落ち着いている。
→ **「改善方向」は信用できるが「(c)=0.811 / +7.6% が最終値」とは言えない**。
延長 run (`run_0077_ext_reichardt` / `run_0078_ext_spalding`, 各 60000 step) で
(c) と $\theta$ が頭打ちするまで確認してから確定する。

**旧 `wall_model_tau` は別の汎関数だった**: $\rho u_\tau^2$ の節点算術平均を使っており、
正式値 (`twall` 接線成分・弧長×周長重み) と一致しなかった。
**正式評価関数へ揃えた** (`--wall-axisym` を追加)。

### 評価

**これまでの介入で初めて、両ケースが同方向に動き、かつ両方が改善した。**

| 介入 | case/26 (→0.94) | case/40 (→1.0) |

| 現行 Reichardt | 0.7557 | 0.9548 |

| **Spalding 逆解き** | **0.8168** | **1.0063** |

$\omega$ pin と E3 は case/40 を大きく過大化させたが、Spalding は **+0.6% に収まる**。
(case/26 欄は壁出力非依存の (c)、case/40 欄は y+1 内部基準比。)

**ただし採用はまだ決めない**:

1. **これは診断構成であり正式仕様ではない** ($g$ が Reichardt のままで物理的に不整合)。
   採否判定は **§5.2 ③ の整合実験**の結果で行う。**③ の一組は次で固定する**:

   | 項目 | ③ での扱い |
   | --- | --- |
   | $u^+$ (逆解き) | **Spalding** |
   | $du^+/dy^+$ | **Spalding** |
   | `wf_pk` | **Spalding 由来の $g$** |
   | `roK_wf` | **Spalding 由来の $g$** |
   | **E3 (`wf_sprod`)** | **OFF のまま** |

   **E3 まで ON にすると、壁法則整合化と既に棄却した $\omega$ 介入が再び交絡する**。

   **実装上の要件**:

   - **② の診断経路を壊さない**。既存 `FORGE_WF_INV_LAW` (逆解き則セレクタ) の**意味は変えず**、
     **閉包則セレクタを別に設ける** (例 `FORGE_WF_CLOSURE_LAW`)。
     これで「逆解きだけ Spalding」(②) と「逆解き+閉包とも Spalding」(③) を
     いつでも往復して比較できる。
   - **$g$・`wf_pk`・`roK_wf` の A/B 比を診断出力に記録する**。
     $y^+\approx28$ では $g$ を Reichardt → Spalding に替えるだけで概算

     | 量 | 見込み |
     | --- | --- |
     | `wf_pk` | **約 −12%** |
     | 壁モデル $\nu_t$ ゆえ `roK_wf` | **約 +20%** |

     と**二つが逆向きに働く**。合成結果だけ見ても機構が読めないので、
     3 つの比を個別に出さないと ③ の解釈ができない。
2. **case/26 の (c) は延長 run で確定済み** (0.7557 → 0.8168)。
3. case/26 は (c) 0.8168 / (d) 0.8199 で**目標 0.94±0.02 に未達** (ギャップの約 1/3 を回復)。
4. 凍結場見積り (+12.3%) に対し連成は **+6.5%** — **再平衡が約半分を打ち消した**。
   凍結場は向きと桁の予測には使えるが、量の予測には使えない。
5. case/40 は圧縮性・熱伝達があり、**非圧縮 Spalding をそのまま正式採用するのは依然として危険**。
   壁温は +0.9 K と小さいが、等温壁ケースでの $q_w$ 判定は未実施。
