## 1. 目的

①軸対称風洞ノズルを**モード F (中心線マッハ全権)** で設計できる状態にする。核心は
**帰還エンジンの初実装** (親計画 §4.7 の 3 段構成のうち v1・v2):

- **v1 (MOC 逆設計)**: starting line + 軸目標 $M_c(x)$ → 逆マーチで超音速場を充填 →
  **質量流量法**で壁流線を抽出 → **δ\* 経験式**の法線オフセット。CFD なし・ミリ秒
- **v2 (Euler 帰還)**: forge Euler (cell) で検算し、軸 $M(x)$ 残差を v1 特性線網の
  **凍結対応マップ**で壁へ帰還。$\|\Delta M\|_\infty \le 0.5\%\,M_d$ までパス反復

検証は「既知目標分布 → 逆設計 → forge 実測 → 目標回復」の自己一貫 + 一様性
$\varepsilon_M,\varepsilon_\theta$ の実装。MOO (co-kriging 多忠実度)・凝縮確認メニューは
本 plan の後半ステップ (7–8) とし、v1/v2+照合の成立を先に確定する。

### 9.2 作戦 (この順で進める。**A が完了するまで計算を投入しない**)

**A. 実験条件・測定の健全化**
- A1 blend を真に無効化 (呼び出し側 fallback 0.0) + 問題 YAML に明示。**汚染 run (0004–0007) は削除も再利用もせず台帳に「破棄予定」として記載**し、以後は必ず**新しい連番 (run_0008 以降)** で投入する (既存 run を使い回さない — AGENTS ルール。初回 0006/0007 を同名で作り直したのは違反だった)
- A2 **完了 (2026-08-14)**: $\varepsilon_M$ の幾何を**出口境界面の実 connectivity**
  (`BCONDS/2/iPlanes` + `PLANES/surfArea`) から取るよう書き換え。軸対称では面中心が
  半径中点なので $2\pi r_c dr=\pi(r_{out}^2-r_{in}^2)$ が**厳密** (実測 max rel 2.5e-5、
  総和は $\pi r_{wall}^2$ と 1e-5 で一致) — 仮想境界は不要になった。壁半径も最外面の

  補間積分も `n_grid` で交差検証でき、面積積分と一致 (0.173% vs 0.173%)。
  **テストコア = 有効菱形の上流境界を実場で C⁺ トレース**して決める
  (`core_radius_traced`)。直線近似 $(x-x_d)\tan\mu_d$ は特性線が一様域でしか直線でない
  ため近似で、実測は トレース 0.835 vs 直線 0.824 (0.7% 差)。**「リップ平面でちょうど壁に
  達する」という旧 docstring の主張は誤りで、コアは壁半径に届かない**ことを確認・訂正した
- A3 **各パスに CFD 健全性ゲート** (既存ルールを弱めない): `check_convergence.py` の VERDICT を**必須**として記録し、加えて報告量の `check_quasisteady.py`・残差の絶対レベル・時系列を**併用**する。**NOT CONVERGED を独自ゲートで「収束相当」に読み替えない** — 未収束なら未収束と明記し、その場を「収束場」と呼ばない

**B0. 遷音速 starting line の壁角 — 観測と、既定変更の撤回 (2026-08-14)**
- 観測: Sauer 解は線形化壁 BC $\bar v=dr_w/dx$ を満たすのに `theta()` は
  $\operatorname{atan2}(\bar v,1+\bar u)$ なので、壁足の θ は円弧接線より 25.7% 小さい
  (R=2 で 5.892° vs 7.394°)。$\theta=\arctan\bar v$ にすると 7.639° と近づき、
  リップ半径 / 1D√ε も 0.9964→0.9990 になる。
- **しかし既定化は撤回** (レビュー指摘): (i) `mach()` は速度ベクトル $(1+\bar u,\bar v)$
  から M を出すので、$\theta=\arctan\bar v$ にすると **M と θ が別の速度ベクトルを
  指す**不整合が生じる。(ii) **壁足 θ は `th_wall0` で円弧接線に上書き済み**なので
  「starting line が 1.5° のキンクを直接渡していた」という説明も不正確。
  → 既定は `exact_ratio` に戻し、`linearized` は**実験オプション**として保持。
- 「**Kliegel–Levine が必須**」という結論も**現時点では導けない** (撤回)。一次資料
  照合と整合試験 (M と θ の整合・格子収束) を経てから判断する。

**B. C2 接続を保証する (本丸)**
**B1 と B2 は別の対象を保証する** (混同しない):

- **B1 = 中心線 Cauchy データの C2 整合**: starting line における目標 $M_c$ の $M''(x_0)$ を Sauer に整合させる (Sivells の古典要件 — サーベイ A0/B2)。現行は $-0.483$ vs $+0.326$ の符号違い。CP を 1 個増やし探索次元は不変に保つ。
  **これは中心線データの整合であって、壁の C2 を保証するものではない** (仮説であり確定ではない)
- **B2 = 円弧と壁形状の幾何学的 C2 接続**: 始端で $r,r',r''$ を円弧に一致させた B-spline を逆 MOC 点列に**最小二乗フィット**。バッファ領域を作らず、形状表現そのものに C2 を内蔵する
- **壁足の接線跳びの原因を確定した (2026-08-14 診断、以前の「楔未計算が原因」は撤回)**:
  1. **被覆図**: 楔 (starting line 直後・壁近傍) は**密に計算されており空隙はない**。
     壁流線は補間の空白を跨いでいない (`case/41/wedge_coverage.png`)。
  2. **解像度収束**: `n_start` 41→81、`n_axis` 400→800、`dx_wall` 0.02→0.01 のいずれでも
     壁足 $\tan\theta[1]$ は **0.071–0.102 で振れるだけで円弧の 0.1298 に近づかない**
     (一方 $r(x_0{+}0.2)$・リップ半径は 4 桁収束)。→ **離散化誤差ではない**。
  3. **$R$ スイープで摂動オーダーを確認** (決定打):

     | $R$ | $\bar u$(壁) | Sauer $\theta_w$ | 円弧 $\theta$ | 不整合 | 設計壁 $\tan\theta[1]$/円弧 |
     | --- | --- | --- | --- | --- | --- |
     | 2 | 0.300 | 5.892° | 7.394° | 1.502° | 0.578 |
     | 5 | 0.142 | 2.262° | 2.559° | 0.297° | 0.919 |
     | 10 | 0.091 | 1.208° | 1.313° | 0.105° | 1.032 |
     | 20 | 0.066 | 0.708° | 0.753° | 0.045° | 1.131 |

     相対不整合は $\bar u$ にほぼ比例 (比 0.68→0.90 で 1 に漸近) — $\theta=\arctan(\bar v/(1+\bar u))$
     と線形化壁 BC $\bar v=dr_w/dx$ の差が $O(\bar u)$ である事実と**定量的に一致**。
  4. **結論**: 真因は **Sauer 一次遷音速解の精度**。$R=2$ では starting line の壁で
     $\bar u\approx0.30$ と摂動が小さくなく、壁流れ角に 26% の誤差が出る。
     **C⁺ マーチ (壁帯被覆) でも B2 (壁の表現) でも直らない** — 前者は被覆問題を解く
     ものだが被覆は既に足りており、後者はデータに反する曲率を押し付けるだけ。
  5. **選択肢** (どちらを採るかは設計判断):
     - (a) **Kliegel–Levine 高次遷音速解**を実装する — $R$ の制約が外れる正攻法
     - (b) **① を $R\gtrsim5$ に限定**する (不整合 0.3° 以下、壁足も 8% 内)。風洞は
       元々スロート曲率が大きい方が一様性に有利なので実用上は成立し得る。ただし
       $R$ は dv なので探索範囲に下限制約が付く
- **B3 効果の分離は 2×2 で行う**: (現行) / (B1 のみ) / (B2 のみ) / (B1+B2) の 4 条件を、A 完了後の測定器と収束ゲートの下で比較し、壁曲率の跳びと圧力波の消失を判定する

**B4. 接合部を壊さない狭幅マスク A/B (2026-08-14 — 「初期形状は帰還が直す」前提の再確認)**
- **前提の再確認 (ユーザ指摘が正しい)**: 初期形状が多少悪くても、帰還がその場所を
  動かせて誤差を観測でき反復が収束するなら最終形状は直る。実測でも**中域 (重み 1.0)
  は $|\Delta M|$ 0.1156→0.0180 (6 倍改善)** の一方、**接合帯 (重み 0.00–0.18) は
  0.1176→0.1168 とほぼ不変** — これは「Sauer 誤差が帰還不能」ではなく
  **「帰還をほぼ掛けていなかった」**と読むべき。KL / 遷音速 CFD へ進む前にマスクを疑う。
- **ただしマスクを単純にゼロにしない**: 円弧は固定・下流壁は可動なので、接合点で
  $\Delta r=\Delta r'=\Delta r''=0$ を保ったまま**直後の曲率だけ**変えられる必要がある。
  流れ角で与えるなら $\Delta\theta(x_j)=\Delta\theta'(x_j)=0$、すなわち
  $\Delta\theta=O((x-x_j)^2)$ で立ち上げる (`junction_taper`, 既定 quintic)。
- **実装で判明した別バグ**: 旧 `_rebuild_wall` は $r$ を `np.gradient` で微分して
  $\theta$ を作り再積分しており、この往復が **接合点の $r''$ を 0.50→0.25 と半減**させ、
  **解像度に依らなかった** ($r$ の $O(h^2)$ 誤差が 2 階微分で $O(1)$ になるため)。
  → $\theta$ を**主変数として持ち回る**形に変更。補正ゼロの往復誤差は
  $\Delta r''=9\times10^{-12}$ (n=1000) / $-9\times10^{-11}$ (n=4000) まで落ちた。
- **接合保存の数値検証** (テーパ幅 0.3, quintic): $\Delta r(x_j)=0$ 厳密、
  $\Delta r'(x_j)$ = −2.3e-6 → −5.4e-8、$\Delta r''(x_j)$ = −1.1e-3 → −7.5e-5
