(旧「1.1226 倍」は別評価系の応答比で、y+1 内部基準比 1.1414 と等号では結べない)。

→ **今回試した 3 つの $\omega$ 介入では両ケースのゲートを同時に満たせなかった**ので、
**独立性の高い代表点経路を次に診断する**。

**「$\omega$ 側を出し切った」「単一ノブでは閉じない」とは言わない**:
$\omega$ の輸送・ブレンド・適用範囲・$k$ との結合は未検証であり、また
**代表点アルゴリズムという単一の構造変更が平板と曲面で逆向きに働く可能性**も残る。

## 2. ★ 前提: 「第一内層速度が低い = 代表点選択の誤り」と即断しない

低い速度は**低い壁応力と自己整合した解の結果**でもある
(親 plan で確認: 課した $\tau_w$ と BL 発達が互いに整合)。
**壁解像場を同じ物理位置へ補間して初めて**、サンプリングの問題か場の問題かを区別できる。
したがって §3 の 3 要因を**分離してから**アルゴリズムに手を入れる。
**いきなり選択アルゴリズムを変更しない。**

## 3. 3 要因の分離 (この順)

### 3.1 代表点選択の幾何

各壁点について出力する:

- 選ばれた `irep`
- $y=(\mathbf{x}_I-\mathbf{x}_W)\cdot(-\hat{\mathbf n})$ (壁関数が使う法線距離)
- 実距離 $|\mathbf{x}_I-\mathbf{x}_W|$
- `best_cos` (内向き法線との cos。現行の選択基準)
- 接線方向オフセット $|(\mathbf{x}_I-\mathbf{x}_W) - y\,(-\hat{\mathbf n})|$
- `wall_dist[irep]`$/y$ (壁距離場との整合)

**現行は「内向き法線との cos 最大」だけで選んでいる**ので、曲面やコーナーでは
「法線上で最適なサンプル点」とは限らない。case/26 (平板) と case/40 (曲面ベル) で比較する。

### 3.2 代表点の速度場

- $U_t(\texttt{irep})$ (壁接線速度の大きさ)
- $\rho,\nu$ (代表点の値)
- 解いた $u_\tau$
- 壁法則残差 ($U_t/u_\tau - u^+(y^+)$ の収束後の値)
- 感度 $du_\tau/dU_t$

case/26 と case/40 で比較し、**どちらのケースで代表点速度が基準からどうずれているか**を見る。

### 3.3 法線補間による 3 分離 (核心)

**同じ粗メッシュ場の中での法線補間**を挟むのが要点。壁点 $\mathbf{x}_W$ から内向き法線
$\hat{\mathbf n}_{\rm in}$ 上、代表点と同じ距離 $y_{\rm rep}$ の位置で速度を補間し、3 つを比べる:

$$\underbrace{U_{t,\rm coarse}(\texttt{irep})}_{\text{現在選んでいる斜め隣接ノード}}
\;\text{vs}\;
\underbrace{U_{t,\rm coarse}(\mathbf{x}_W+y_{\rm rep}\hat{\mathbf n}_{\rm in})}_{\text{粗場を法線上へ補間}}
\;\text{vs}\;
\underbrace{U_{t,\rm ref}(\mathbf{x}_W+y_{\rm rep}\hat{\mathbf n}_{\rm in})}_{\text{壁解像場を法線上へ補間}}$$

| 比較 | 分離できる要因 |
| --- | --- |
| 現隣接点 vs **粗場法線補間** | **代表点選択・接線オフセットの影響** |
| 粗場法線補間 vs **壁解像法線補間** | **粗メッシュ速度場そのものの影響** |
| 壁解像速度を Reichardt 則へ入力した $u_\tau$ vs **壁解像の真値 $u_\tau$** | **壁法則自体の影響** |

> 3 つ目は「$U_{t,\rm coarse}=U_{t,\rm ref}$ なのに $u_\tau$ が違う」という書き方をしない。
> 同じ $y,\nu,U_t$ を与えれば壁法則の解は**一意**なので、比較すべきは
> 「**基準速度を壁法則へ入れて得た $u_\tau$**」と「**壁解像の真値 $u_\tau$**」である。

## 7. §3 の結論 (2026-08-13)

1. **case/26 の欠損に代表点選択は無関係** (`best_cos`=1.0000)。**端点比分解**は
   選択 1.000 / 速度 1.0528 / 壁法則段 1.0425。積が一致するのは**中間状態を定義した比の積で
   代数的に自明**であり、**因果寄与の一意な分解ではない**。物性は粗場の $\nu,y_{\rm rep}$ に固定
   (速度段が速度だけの寄与になるように)、壁法則段には物性・$y$ 定義差と基準解自身の誤差が混ざる。
2. **壁解像基準のプロファイルが、採用した Reichardt 相関を $y^+$≈30 で約 5.1% 下回る**
   ($x$ 非依存)。**壁法則自体が誤りという証明ではない** — 壁解像解の誤差・有限 Re・入口条件・
   自由流乱流・物性定義が含まれる。**自由流乱流は候補 B で棄却済み** (§10)。
   さらに壁法則スイープ (§10) で **Spalding では逆に +2%** になることから、
   **壁法則の選択が観測差と同程度のモデル形式不確かさを持つ**ことが分かっている
   (ただし forge/SU2 とも SST なので**共通の SST モデル誤差は未除外**)。
3. **case/40 には実サンプリング誤差がある**: 代表点が法線から 30% ずれ、
   **同じ $y$ の法線上より 21–27% 高い速度**を読む。
4. **両ケースの符号が逆だった理由の仮説**: case/40 では選択誤差が速度を過大に読み、
   粗場の不足を部分的に相殺している。case/26 は相殺がない。
   → 同じ $\omega$ 介入で一方が不足のまま・他方が過剰になる。
   **(1)/(2) (同一場・2 位置) だけが純粋なサンプリング量**であり、(2)/(3) は別々の
   収束解の比較なので解の違いが混ざる (§2 の注意)。

**正式値は要素補間に統一**する。

### 候補 B (自由流乱流条件) — **仮説を棄却**

$\mu_t/\mu$ を 65.9 / 1.0 / 0.009 の 3 条件 (最後は TMR 推奨範囲内で選んだ値) で
壁関数 y+27 と壁解像 y+0.7 のペア × 3 を実施 (`run_0063`–`run_0066`)。

**収束の位置づけ**: 4 run とも**全残差では `NOT CONVERGED`** (`rms_roOmega` が 0.5dec で停滞、
`run_0064` は最終 2.77)。**判定対象の $\theta$ と $C_f(Re_\theta)$ は `STEADY`**
($\theta$ drift 0.0–0.3% / $C_f/C_{f,\mathrm{KS}}$ drift 0.1% / fluct 最大 0.4%)。

実測主流 $\mu_t/\mu$ は指定どおり 4 桁にわたり追随したが、
$C_f/C_{f,\mathrm{KS}}$ は 0.764 (壁関数) / 0.944→0.943 (壁解像)、Reichardt 比は 0.9492→0.9494。
**「一切動かない」ではなく「今回の準定常量では検出可能な変化がない」**と表現する。
→ 自由流乱流を 5.1% 差の主因候補から外す。

### SU2 クロスチェック — **forge 固有の壁解像誤差をほぼ除外**

**全残差収束済み**の SU2 壁解像 (`run_0049_su2_sst_lowre_fine`, rms −5.0〜−12.6) を
同じ要素補間・同じ $y_{\rm rep}$=1.7681e-4 で評価:

| $x$ | 実測/Reichardt |
| --- | --- |
| 0.451 | 0.9490 |
| 0.602 | 0.9483 |
| 0.694 | 0.9480 |
| 0.800 | 0.9477 |

forge 壁解像の 0.9492–0.9504 と **0.1–0.2% で一致**。
独立した 2 コード (一方は全残差収束) が、この境界層は $y^+\approx30$ で
Reichardt 相関を約 5% 下回ると一致して示す。
→ **forge 側の壁解像誤差・物性定義・壁応力定義は主因から除外**。
