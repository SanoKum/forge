## 2. 確定した事実

1. **SU2 は解析的回復温度に +1.5–2% で一致** (1431 vs ~1400 K)。物理的に正しい断熱壁。
2. **forge の壁温 −240 K は node 固有ではない** — 同一メッシュの cell も同水準 (1186 vs 1196 K)。
   実効回復係数 r≈0.72 で、層流回復 (r=√Pr≈0.85 → ~1337 K) すら下回る = 単なる
   層流化ではなくエネルギー輸送の欠損。
3. **犯人は `wallTreatmentSST=1` (automatic 壁関数、forge 既定 ON)**: OFF (low-Re 積分) にする
   だけで cell は SU2 と 1 K 差まで回復し、BL の μt も 1 桁回復する。dilatation 補正 (D1) は無罪。
4. **forge−SU2 の η 差 2–3% も同根**: 壁処理を SU2 と揃えた D2 で η 0.9549 vs SU2 0.9573。
   壁関数 ON の η 0.981–0.988 は「薄い BL」側の値。
5. node の壁 T 市松残余 (断熱リーク修正後 43.7 K) は **wf=0 で 19.9 K までさらに半減** —
   残余市松の相当部分も壁関数系 (wf_pk/τ_w/k ピン) 経由だった。
6. (既報) 断熱壁の伝導リーク (node のみ、修正済み) は別問題で、これは市松 206→44 K と
   壁温 1631→1196 K (Tt 超えの非物理の解消) を説明する。

## 3. 機構の推察

forge の automatic wall treatment (wallTreatmentSST=1) は**運動量・乱流側のみのモデルで、
エネルギー側の壁法則を持たない**:

- 第一セル/第一内層の k 生産を wf_pk=ρu_τ⁴/ν·g(1−g) に置換し、ω をピンし、壁せん断を
  modeled τ_w=ρu_τ² に置換する (SU2 AddTauWall 移植)。y+≈19–40 は**バッファ層〜対数層下端**で、
  この帯では置換生産が実勾配生産より小さく、BL 全層の k → μt が 1/10 に絞られる
  (memory: wf=1 の想定滞在域は y+~30–80 の対数層)。
- 断熱壁温は「BL 内の粘性散逸熱が乱流伝導で壁へ運ばれて成立する」量。μt が 1/10 だと
  散逸そのもの (μt·S² 系) と壁への熱輸送 (k_eff=κ+cp·μt/Prt) の両方が細り、**回復が成立せず
  BL 全層が冷える** (壁点だけの問題ではない — §1.2 のとおり全層 −150〜−280 K)。
- 一方 WMLES 経路には Kader 温度壁法則 (q_w/T_aw モデル) があるが、**SST 壁関数経路には
  熱側の対応物がない**。つまり「τ_w はモデル化するが T_aw はモデル化しない」非対称が、
  中途半端な y+ 帯で顕在化した。
- SU2 は今回壁関数なし (low-Re 積分)。y+≈20 は low-Re に粗すぎるが、解像勾配から SST が
  素直に μt を立てるため回復温度は自然に成立する (BL 損失は過大評価側に振れ、η は低め)。

**総合すると、現メッシュ (y+≈19–40) は low-Re にも壁関数にも不適な帯に居り、
forge wf=1 は「η 高め・壁温 −240 K」、forge wf=0 / SU2 は「壁温正・η 低め」に振れている。
真値は y+≈1 メッシュ (low-Re) か y+>30 メッシュ (壁関数) で挟み込まないと決まらない。**

## 4. 留意点 (この結論の限界)

- D2/D3 は wf=1 の収束場からの再平衡 12000 step で、VERDICT はプラトー (quasi-steady)。
  特に D3 (node, wf=0) は ṁ が 4.5% 低下しており (1.2336)、node の low-Re 経路
  (壁 ω=60ν/βy² を wall_y_eff で評価) の妥当性・収束は未検証。D3 は「方向性の証拠」に留める。
- node wf=0 の壁温 1378 K は SU2 の 1431 K に対しまだ −53 K。残余市松 19.9 K と併せ、
  node 壁エネルギー経路 (W–I 対流/τ·u) の監査は継続対象。
- η の絶対値は依然 surrogate (格子収束・Rao 照合未実施)。今回の発見は
  「surrogate の系統誤差の主因が壁処理」という帰属の前進。

## 7. 訂正 (2026-08-11, Codex 対照実験による)

Codex の追加対照 (SU2 に `STANDARD_WALL_FUNCTION` を付けた `run_0030_su2_sst_wallfunc`) により、
§3 の機構推察を次のとおり**訂正**する:

- **「wf_pk が BL 全体の乱流を絞め殺したことが主犯」は棄却**。壁関数同士の比較では第一内点の
  状態は近い (SU2 μt/μ=6.9・T=1015K vs forge 3.8・997K、ṁ も一致) のに、壁温だけが 1422K vs
  1193K と違う。§1.2 の「μt 1/10」は forge-壁関数と SU2-low-Re という**異なる壁処理の解族を
  混ぜた比較**であり、機構の証拠にならない。
- **真因は forge SST 壁関数に断熱回復温度の熱的閉包 (Crocco–Busemann) がないこと**。SU2 壁関数は
  T_aw = T_1 + Pr^{1/3}U_t²/(2cp) で壁温を更新しており、forge の第一セル値をこの式に入れると
  SU2 と ~4K で一致する (Codex)。forge 側に `Taw_diag` 診断を実装して確認: ベル部 mean 1420.2K
  = SU2 壁関数 1422K と 2K 差。
- wf=0 (D2) の SU2-low-Re との一致は「同じ (未解像の) low-Re 解族に乗った」ことを示すだけで、
  どちらが真かは y+≈1 系列がないと言えない。η 0.955〜0.988 の真値も同様に未決。
- 分子 Pr の不整合 (Sutherland μ + 固定 k → Pr 1.5–1.87) は実在するが −230K の主因ではない
  (SU2 対照 +14.7K / forge constant-Pr 実装 −25K)。`thermCondMethod: 1` として修正オプションを実装済み。
