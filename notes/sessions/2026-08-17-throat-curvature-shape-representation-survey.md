## 1. 対象ケースと現在の設計チェーン

- ケース: `case/41.wind_tunnel_design`、①軸対称風洞 (モード F)
- 設計点: $M_d=4$ / $P_t=1$ MPa / $T_t=800$ K / $r_t=10$ mm / $\gamma=1.4$
- 座標は特記なき限り**スロート半径 $r_t$ で無次元化** ($x/r_t$, $r/r_t$)

**壁の区分構成** (`design/forge_design/geometry/wall_modef.py` の `ModeFWall`):

```
入口直管 → Bell–Mehta 5 次収縮 (両端 C2)
        → 単一円弧 R=2 ($R_u=R_d$、$\varphi_u=25°$ からスロートを経て $J$ まで)
        → [J] → 逆 MOC 設計壁 (点列を通す 5 次 B-spline)
        → リップ (x/r_t ≈ 24.7)
```

- **接合点 $J=(x_j, r_j)=(0.2465,\ 1.0153)$** — 固定円弧の終端 = 可変設計壁の始点
- 設計壁は**逆 MOC** (`geometry/moc_inverse.py`) が軸中心マッハ目標 $M_c(x)$ から
  生成する点列を、**左端で円弧の解析 $r', r''$ にクランプした 5 次 B-spline**
  (`scipy.interpolate.make_interp_spline(k=5, bc_type=...)`) で通したもの
- 目標 $M_c(x)$ は Bézier (CP の $x$ 等間隔固定、自由 CP 3 個 + 端点拘束)

**設計フロー**: 目標 $M_c(x)$ → 逆 MOC → 壁点列 → `ModeFWall` → 構造化メッシュ
→ forge (Euler, 軸対称) → 軸 $M$ の実測 → 残差を壁へ帰還 (特性線マップ経由) →
壁更新 → 反復。

## 2. 症状 (実測値)

### 2.1 軸マッハ数のこぶ

軸上 $M(x)$ を自身の 5 次トレンドから引いた「うねり」(意図非依存の指標):

| 位置 | 値 |
| --- | --- |
| こぶ頂 | $x/r_t \approx 1.43$、振幅 **+0.019〜+0.023** |
| 谷 | $x/r_t \approx 1.86$、**−0.026〜−0.031** |
| 山→谷の最大勾配 | 0.105 → 0.125 (格子細分で +19%、**鋭くなる**) |

- **格子収束する**: 接合部近傍のみ軸方向を 1x/2x/4x に細分しても振幅 0.0218 →
  0.0222 → 0.0227、位置 1.404 → 1.427 → 1.432 と収束方向。数値アーティファクト
  だけではない。
- **cell / node 両方に残る** (node: 振幅 0.0187 @1.44)。ただし**物理と断定するには
  スキーム収束の確認が未了**。

### 2.2 壁マッハ数勾配の折れ

CFD 実測の壁 $M$ を接合点の両側で線形近似すると

$$\frac{dM}{dx}\Big|_{\text{円弧側}} = 0.989 \quad\longrightarrow\quad \frac{dM}{dx}\Big|_{\text{設計壁側}} = 0.595$$

と 40% 跳ぶ。**注意**: 壁 $M$ は境界条件ではなく観測量なので、これは「原因」では
なく「結果」。因果を逆に述べないこと。

### 2.3 到達可能性の境界

固定円弧終端 $J$ から出る C⁻ 特性線を実 CFD 場で追跡すると、軸への着地点は
$x_{\mathrm{reach,CFD}} = 1.704$ (格子ばらつき 0.004)。**$x < x_{reach}$ の軸 $M$ は
設計壁のどの自由度でも動かせない** (実測: 3 種類の壁で $x<1.7$ の軸 $M$ が 4 桁目
まで一致)。こぶ頂 (1.43) はこの**到達不能域の中**にある。

## 3. すでに試して**効かなかった / 撤回した**こと

同じ道を再提案されても困るので、経緯を明記する。

| 施策 | 結果 |
| --- | --- |
| **曲率ブレンド** (円弧終端から `blend_len` だけ 5 次 Hermite で曲率を繋ぐ) | **撤回**。健全な逆設計壁を上書きして出口指標が悪化 (0.173% → 1.166%) |
| **接合の C2 を壁表現で厳密化** (not-a-knot 3 次 → 左端クランプ 5 次 B-spline) | $r''$ の跳び (+0.51 / −3.21) は解消し**表現としては正しくなった**が、**こぶは不変** (接合帯 0.1176 → 0.1152) |
| **中心線 Cauchy データの C2 整合** (目標 Bézier の $M''(x_0)$ を遷音速解に一致) | 単独では効果限定的 |
| **こぶを逆設計の目標に写す** | **壊滅** ($\Delta M$ 1.84)。こぶは円弧が作る波の*結果*なので目標化すると設計壁が同じ波を再生成 (原因の二重計上)。$M$ 減少区間の Cauchy データが特性線を収束させ逆設計が悪条件化 (壁 $d^2\theta$ が通常の 20 倍) |
| **遷音速 Cauchy データを CFD 実測に置換** (Sauer 一次解 → CFD 抽出) | **最も効いた**。接合波が **58% 減** (0.118 → 0.050)。Sauer 一次解は実 CFD と $M'$ が +25%、$M''$ が 2.3 倍ずれていた |

**現在の未解決点**: CFD 実測を継承しても振幅 ~0.019 のこぶが残る。

## 4. いま直面している設計上のジレンマ (調査の動機)

$x_{reach}=1.704$ で CFD の実測値を C2 継承する方式に変更したところ:

| $x_{reach}$ での値 | $M$ | $M'$ | $M''$ |
| --- | --- | --- | --- |
| 旧目標 (大域 Bézier) | 1.93890 | **+0.5106** | **−0.1960** |
| CFD 実測 (node, 最細格子) | 1.94576 | **+0.2896** | **+0.1900** |

**旧目標は始端で実流と大きく食い違っていた** ($M'$ が 76% 違い、$M''$ は符号が逆)。
CFD 値を C2 継承すると目標形状が最大 **0.076** 変わり、**自由 CP 3 個ではこれを
吸収できず出口一様性が悪化**した ($\varepsilon_M$ 0.023% → 0.128%、
$|\theta|_{max}$ 0.015° → 0.183°)。

→ **「始端の曲率整合」と「出口の一様性」が現在の形状表現では両立しない。**
これが本調査の動機である。

## 5. 調査してほしいこと

### Q1. 古典的ノズル設計法は throat 近傍の曲率をどう扱っているか

特に以下を一次資料で確認してほしい (`papers/` に PDF があるものは参照、無ければ
書誌情報と入手可否を報告):

- **Sivells (1978 ほか)** の軸対称ノズル設計法 / **CONTUR** コード
  — 「曲率連続の非粘性コンタ」を要件にしていると理解しているが、**具体的に
  どの量を、どの区間で、どう連続にしているのか**を明確にしてほしい。
  throat 近傍に専用の解析形状 (円弧以外) を使っているか?
- **Foelsch**、**Rao (TOC/TOP)**、**Beckwith/Moore** 系の風洞ノズル設計
- 「$R_d$ (スロート下流曲率半径) が一様性に与える影響」を定量した文献
  — 本ケースは $R_d=2 r_t$ で、$\bar u$ が大きく遷音速摂動が小さくない。
  風洞では $R_d$ を大きく取る (5〜10 $r_t$) のが定石か? その根拠は?

### Q2. 曲率・曲率微分を直接制御する形状表現

- **G2/G3 連続**を保証する曲線表現 (Bézier/B-spline/NURBS の幾何連続性)
- **曲率を設計変数にする**アプローチ — 例: $\kappa(s)$ を直接パラメトライズして
  $r(x)$ を積分で得る (クロソイド/オイラー螺旋の一般化、curvature-driven design)
- **CST (Class-Shape Transformation, Kulfan)** の曲率制御能力
- 「throat 近傍だけ別の基底を使い、下流と G2/G3 で接続する」ような
  **区分表現の設計事例**
- 曲率の**単調性・符号**を制約に入れる最適化定式化

### Q3. 「接合部を作らない」代替設計

- スロートから下流まで**単一の滑らかな曲線**で表現する方式は実在するか
  (円弧を廃し、$\kappa(x)$ が連続な throat を作る)
- 逆 MOC の starting line 位置と壁形状表現の**整合の取り方**
  — 本ケースは starting line ($M=1.05$ の縦線) の壁足と円弧終端が同一 $x$
  にあり、そこが可変壁の始点になっている。この構成は一般的か?

### Q4. 二階微分の「測定」側

- 設計・検証で $M''$ 相当の量を扱う際、文献ではどう測っている/定義しているか
  (本ケースでは CFD 軸 $M$ の局所回帰で得るが、離散化雑音に弱い)

## 6. 制約・前提 (提案時に守ってほしいこと)

- **既存資産を壊さない**: 逆 MOC・CFD 帰還ループ・出口指標は動作しており、
  形状表現だけを差し替える提案が望ましい
- 自由設計変数は現在 3 個 (中心線マッハ Bézier の自由 CP)。**増やす提案は可**だが
  探索コスト (MOO 段で EHVI 最適化する) への影響を明記すること
- 円弧 $R$ は設計変数 ($R \gtrsim 5$ に制限する案も検討済み)
- **CFD は node (median-dual) を基準**とする方針 (cell は回帰対照)
