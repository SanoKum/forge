## ⚠ 訂正 (2026-08-16, 壁形状の可視化で判明)

**$L_c \le 4$ の CFD は「壊れた壁」で回っていた**ため、下表の $L_c$=4/3/2/1.5/1 の
数値は物理的劣化を過大評価している。`AxisMachCFDWall` はスロート端で
$\kappa = 1/R$ にクランプした**補間** 5 次 B-spline だが、MOC 壁自身の
スロート近傍曲率は $L_c$ とともに爆発する:

| $L_c$ | MOC 生テーブルの $\kappa$ ($x<0.5$) | クランプ BC $1/R$ | spline の $\theta$ リンギング |
| --- | --- | --- | --- |
| 9.715 | 0.46 | 0.50 | +0.02° |
| 7.0 | 0.54 | 0.50 | 0.00° |
| 6.0 | 1.06 | 0.50 | +0.01° |
| 5.5 | 2.18 | 0.50 | 0.00° |
| 5.0 | 5.84 | 0.50 | 0.00° |
| **4.0** | **15.4** | 0.50 | **+25.3°** |
| **3.0** | **12.2** | 0.50 | **+36.0°** |

生テーブルの $\theta_{\max}$ は全 $L_c$ で 17–21° に収まるのに、$L_c$=3 の spline は
**56.9°** に達する。BC とデータの矛盾が補間スプラインを振動させたもの。

**影響範囲**: ゲート境界の判定 ($L_c$=6 合格 / 5.5 不合格) と $L_c$=5 の衝撃波診断は
**リンギング 0.00° の領域なので無傷**。結論 1・2・4・5 は維持する。$L_c\le4$ は
「表現の破綻 + 物理の破綻」が混ざった点として読むこと。

**追加の教訓**: 壁 QA は曲率の**連続性**(接合部) は見るが**大きさ・振動を見ていない**。
生テーブルと spline の乖離チェック (例: 点上で $|\theta_{spline}-\theta_{tbl}|$ 上限) を
入れれば自動検出できた。

**→ 実装済み (2026-08-16)**: `wall_qa(..., R=R)` のスロート曲率整合ゲート
($|\kappa_0R-1|\le0.15$、$\kappa_0$ は $r-1=\frac{\kappa_0}{2}x^2$ の LSQ) と
`AxisMachCFDWall.validate()` のリンギング検査 ($\le0.2°$)。生産解像度 n=500 では
$L_c\le5.5$ が設計段階で REJECT され CFD の崖と一致。壁表現は補間スプライン +
上流クランプを維持 (近似化は矛盾を隠すだけ — ユーザ判断で不採用)。

## 結論

1. **実用下限は $L_c \approx 6$** (0.437%、ゲート内)。マージンを取るなら **$L_c=7$** (0.357%)。
   崖は 6→5.5 の間で誤差が倍増する。
2. **崖の正体は内部衝撃波** (物理であり数値でない)。$L_c=5$ の ΔM は符号反転する波形
   (圧縮波の集束)、$L_c=3$ では実測 M が目標を −0.70 下回り続ける (衝撃損失で全圧が
   失われ、同じ面積比でも M が出ない)。急峻な $M''<0$ の減速尾部が生む圧縮波が
   短ノズルでは壁到達前に集束する。逆 MOC は衝撃なしを仮定するので、この領域では
   設計自体が自己不整合。
3. **壁 QA はこれを検出できない** (characteristic crossing チェック未実装) — 設計側の
   ゲートは全 L_c で ok を返した。将来課題: C⁻ 間隔の符号監視 or $M''$ 由来の
   集束距離見積りを QA に足す。**あわせて曲率の大きさ・spline リンギングの検出も**
   (上記訂正参照)。
4. **全長の床は表現ではなく物理**。ゲート内で $x_F$ は 22.85 → 19.11 (**16% 短縮**が上限)。
   $x_F - x_E \approx 12.6\,r_t$ (終端特性線の一様化区間 $\approx r_F\sqrt{M_d^2-1}$) は
   $L_c$ に依らず固定で、これが全長を支配する。加速区間をゼロにしても全長は
   ~14 $r_t$ までしか縮まない — 一様出口の要求そのものの代価。
   (ユーザ指摘の「L は多項式の表現次第」は**上限側**に正しい: 単一 quintic の単調
   ゲートが $L_c \le 9.9$ を課す。より長いノズルには A6 [knot spline] が要る。)
5. 出口一様性はゲート内の全点でほぼ不変 ($\varepsilon_M$ 0.034–0.036%) — 短縮の代償は
   まず軸 M 追従誤差に出る。

## 生産推奨

長さ要求がなければ現行既定 (Lc_mode: max) を維持。長さを詰める要求が出たら
**$L_c=7$ (x_F=20.15, −12%)** を推奨、$L_c=6$ が下限。
